# ICT 안전 수업 공기질 프로젝트 · DMF 적용

기존 Arduino 스케치, Python 수집기, `air_log.csv`를 **원문 바이트 그대로 보존**하고 DMF의 해시·머클·버전·Restrict·감사 라이브러리를 적용한 실행형 산출물입니다. 기존 보고서의 서식 수정은 포함하지 않습니다.

| 파일·폴더 | 역할 | 사용 방법 |
| --- | --- | --- |
| `tools/dmf_air_quality.py` | 새 결과 생성·읽기 전용 검증 | Python 표준 라이브러리로 실행 |
| `tests/test_dmf_air_quality.py` | 변조·경로·CSV·보존 검사 | 임시 폴더의 격리 자료로 검사 |
| `실행결과/DMF_적용보고서.html` | 표 중심 한글 보고서 | 브라우저로 열기, 밝은·어두운 환경 자동 대응 |
| `실행결과/DMF_적용보고서.md` | 같은 내용을 담은 Markdown | Markdown 뷰어 또는 GitHub |
| `실행결과/원본보존/` | 원본 코드 2개·측정 CSV 1개 | 원본과 크기·SHA-256 대조 |
| `실행결과/봉인_목록.json` | 고정 원본·DMF 의존성 기준 | 프로그램에 고정한 기준과 재대조 |
| `실행결과/분석_결과.json` | 전체 CSV 순회 결과 | 행 수·결측·범위·프로젝트 등급 확인 |
| `실행결과/버전_이력.json` | 로컬 v1·v2 및 해시 체인 | 과거 프로젝트 차수와 구분 |

| `실행결과/파일_무결성.json` | 도구 생성 파일의 크기·해시 | 자기 파일과 별도 PDF는 제외 |
| `assets/` | 나눔고딕 Bold 700과 OFL | 시스템 글꼴 설치 없이 HTML에서 사용 |

[HTML 보고서](실행결과/DMF_적용보고서.html) · [Markdown 보고서](실행결과/DMF_적용보고서.md) · [PDF 인쇄 파생본](실행결과/DMF_적용보고서.pdf)

PDF와 제출용 ZIP은 별도 포장 단계에서 준비합니다. 이 Python 도구가 PDF·ZIP을 생성하거나 DMF 체인에 포함했다고 표시하지 않습니다.

## 준비

Python 3.9 이상과 Git이 필요합니다. `pip install`, 서버·데이터베이스, Arduino 연결은 필요하지 않습니다. Windows에서는 Microsoft Store 실행 별칭 대신 **실제 Python 실행파일**을 사용해야 합니다. 아래 `$python` 변수에는 본인 환경에서 확인한 실행파일 경로를 지정합니다. 실행 예시의 작업 위치는 이 `1차` 폴더입니다.

DMF 소스는 라이선스가 확인되지 않아 동봉하지 않습니다. 원문 저장소를 별도 폴더에 준비합니다. 기존 `work/DMF`가 있으면 다시 복제하지 않습니다.

```powershell
git clone https://github.com/leecursion/DMF.git ../work/DMF
git -C ../work/DMF checkout --detach cf550e3b2ceb0946ba89f64e43b7d6c2f5164383
```

프로그램은 해당 고정 커밋의 Git blob 7개를 읽어 각 SHA-256을 확인한 후 메모리에서 실행합니다. **작업트리 수정은 실행에 반영되지 않습니다.** 원본 코드·CSV에는 줄바꿈 정규화나 수치 수정이 없습니다.

## 기존 결과 재검증

```powershell
$sourceRoot = (Resolve-Path '../../코드/최종').Path
$dmfRoot = (Resolve-Path '../work/DMF').Path
$outputRoot = (Resolve-Path './실행결과').Path
& $python -B -X utf8 ./tools/dmf_air_quality.py verify --source-root $sourceRoot --output $outputRoot --dmf-root $dmfRoot
```

성공하면 `verdict: PASS`와 검사 항목을 출력하고 종료 코드 0을 반환합니다. `verify`는 스냅샷·JSON·보고서·파일 목록을 다시 읽고 비교하며 **산출물을 쓰거나 갱신하지 않습니다.** 이식한 공개 복제본에서 검사할 때도 원본 루트에는 봉인 기준과 동일한 세 파일이 있어야 합니다.

### 제출 ZIP만 풀어 재검증하는 경우

위의 `../../코드/최종`은 GitHub 저장소 전체를 복제했을 때의 기존 원본 위치입니다. 제출 ZIP에는 그 폴더가 없으므로, ZIP의 `DMF 적용 1차` 폴더에서 아래 블록을 사용합니다. 먼저 앞의 DMF 별도 준비를 마쳐야 합니다.

```powershell
$zipSource = Join-Path (Get-Location).Path '재검증용 원본'
if (Test-Path -LiteralPath $zipSource) { throw '재검증용 원본 폴더가 이미 있습니다. 별도의 새 폴더 이름을 지정하세요.' }
Copy-Item -LiteralPath './실행결과/원본보존' -Destination $zipSource -Recurse
$sourceRoot = (Resolve-Path -LiteralPath $zipSource).Path
$dmfRoot = (Resolve-Path '../work/DMF').Path
$outputRoot = (Resolve-Path './실행결과').Path
& $python -B -X utf8 ./tools/dmf_air_quality.py verify --source-root $sourceRoot --output $outputRoot --dmf-root $dmfRoot
```

이 절차는 **동봉한 보존 스냅샷 복사본의 재검증**입니다. 외부에 보관한 독립 원본을 다시 확인한 것으로 해석하지 않습니다. 외부 원본을 보유했다면 그 원본 폴더를 `--source-root`로 지정해 별도로 대조합니다. 원본 폴더와 결과 폴더가 겹치면 도구가 거부하므로 보존 폴더를 직접 입력 경로로 쓰지 않습니다.

## 새 결과 재현

ZIP에서 준비한 복사본으로 새 결과를 만들 때는 아래 첫 줄의 원본 경로를 `./재검증용 원본`으로 바꿉니다. 이미 존재하는 결과 폴더는 덮어쓰지 않습니다. 별도 폴더에서 재현합니다. 생성 시각이 들어간 감사 이력과 이를 포함한 보고서·파일 해시는 실행마다 달라질 수 있습니다. 동일 원본의 `manifest_root`, `restrict_seal`, 버전 해시, CSV 분석값은 같은 기준으로 다시 계산됩니다.

```powershell
$sourceRoot = (Resolve-Path '../../코드/최종').Path
$dmfRoot = (Resolve-Path '../work/DMF').Path
$newOutput = [System.IO.Path]::GetFullPath((Join-Path (Get-Location).Path '재현결과'))
& $python -B -X utf8 ./tools/dmf_air_quality.py build --source-root $sourceRoot --output $newOutput --dmf-root $dmfRoot
```

새 원본이나 새 실험을 기존 봉인 해시에 맞춰 덮어쓰지 않습니다. 원본이 달라지면 이 도구는 거부합니다. 후속 차수의 별도 검토와 새 기준 설정이 필요하며, 현재 파일의 해시를 자동으로 새 baseline으로 바꾸는 기능은 없습니다.

```powershell
& $python -B -X utf8 -m unittest discover -s ./tests -v
```

## 해석과 한계

| 적용한 기능 | 적용 범위 | 남은 경계 |
| --- | --- | --- |
| 콘텐츠 SHA-256 | 원본과 스냅샷 바이트 | 데이터 자체의 센서 정확도는 증명하지 않음 |
| 머클·버전·Restrict | 이번 묶음의 초기 봉인 v1과 분석 추가 v2 | 과거 프로젝트 편집 이력을 재구성한 것이 아님 |
| 감사 체인 | 이번 생성 시각·행위·대상 버전 연결 | 외부 서명·타임스탬프·WORM 미적용 |
| CSV 분석 | 실제 전체 기록, 결측·비정상 행 구분 | 시간대 미기록, 연속 측정 보장 없음 |
| 프로젝트 등급 | 원본 Arduino 함수 판정 순서 재현 | 공인 환경·건강 기준이 아님 |
| 로컬 PASS | 저장 필드·루트·원본·증명 재대조 | 승인 서버·사용자 권한·Shadow/Official 미구현 |
| 별도 PDF | HTML 인쇄 파생본이 제공될 수 있음 | 도구 빌드·DMF 체인·`파일_무결성.json`과 별도, 제출 목록에서 해시 확인 |

같은 권한으로 프로그램과 모든 증거를 다시 작성할 수 있는 주체에 대한 변조 방지·서버 보증 신원을 제공하지 않습니다. 원본 자료, 고정 기준, 검증 실행과 별도 검토를 함께 평가해야 합니다. 장치 재측정·Arduino 업로드·실제 센서 보정은 수행하지 않습니다.
